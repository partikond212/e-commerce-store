# 🛒 e-commerce-store — интернет-магазин на React

**e-commerce-store** — это полноценное SPA-приложение интернет-магазина, разработанное в рамках практики React и смежных технологий. Проект включает авторизацию, корзину, избранное, админ-панель для управления товарами, личный кабинет с настройками профиля и динамическую загрузку данных.

---

## 📦 Стек технологий

| Технология | Назначение |
|------------|------------|
| **React 19** | Основа приложения, функциональные компоненты, хуки |
| **React Router v6** | Клиентская маршрутизация (SPA) |
| **Context API** | Глобальное состояние (авторизация, корзина, товары, избранное) |
| **React Hook Form + Yup** | Валидация форм (регистрация, логин, добавление товаров, смена пароля) |
| **json-server** | Фейковое REST API для товаров и пользователей (можно заменить на реальный бэкенд) |
| **localStorage / sessionStorage** | Хранение данных пользователя, корзины, избранного, товаров |
| **CSS Modules** | Стилизация компонентов, адаптив (mobile‑first) |
| **Vite** | Сборка и разработка |
| **GitHub Pages** | Деплой готового приложения |

## ⚙️ Функционал

### Реализовано:

- ✅ **Главная страница** — слайдер с акционными товарами, список популярных товаров из каталога.
- ✅ **Авторизация и регистрация** — формы с валидацией, сохранение сессии в `localStorage` / `sessionStorage`, поддержка роли `admin`.
- ✅ **Каталог товаров** — динамическая загрузка товаров из `json-server` (или `localStorage` при недоступности сервера).
- ✅ **Карточка товара** — детальная страница с кнопкой добавления в корзину и избранное.
- ✅ **Корзина** — добавление/удаление товаров, изменение количества, расчёт итоговой суммы, сохранение состояния для каждого пользователя отдельно.
- ✅ **Избранное** — добавление товаров в избранное (сердечко), отдельная страница со списком избранных товаров, сохранение в `localStorage` с привязкой к пользователю.
- ✅ **Личный кабинет** — просмотр профиля, редактирование дополнительной информации (телефон, адрес), смена пароля, загрузка аватара (сжатие изображения).
- ✅ **Админ-панель** — добавление новых товаров (название, цена, рейтинг, ссылка на изображение) через форму с валидацией.(Админом можно стать только если вы ввели в форме регистрации email - artmerk91@gmail.com)
- ✅ **Поиск товаров** — автодополнение (debounce) с переходом на страницу товара по клику.
- ✅ **Адаптивный дизайн** — корректное отображение на мобильных устройствах, планшетах и десктопах.
- ✅ **Тёмная/светлая тема** — переключение через настройки профиля (сохранение в `localStorage`).
- ✅ **Обработка ошибок** — уведомления при недоступности сервера, автосохранение данных в `localStorage`.

## 🐞 Баги и проблемы (и их решение)

| Проблема | Решение |
|----------|---------|
| **Изображения не отображаются на GitHub Pages** | Использован `getImagePath()` для корректных путей (добавление `basename` в продакшене). |
| **При обновлении страницы — 404** | Добавлен `basename` в `BrowserRouter` и настроен `404.html` для перенаправления на `index.html`. |
| **После выхода из аккаунта аватар сбрасывался** | Аватар вынесен в отдельный ключ `avatar_original_${userId}`, а сам список пользователей хранит только текстовые данные, чтобы избежать переполнения `localStorage`. |
| **Гость не мог перейти в избранное** | Маршрут `/favorites` вынесен из‑под `PrivateRoute`, внутри добавлена проверка на авторизацию. |
| **Корзина не разделялась между пользователями** | Ключи корзины привязаны к `user.id` (`cart_${userId}`), при выходе загружается корзина гостя. |
| **CORS при загрузке изображений в админке** | Отказ от внешних сервисов в пользу ручного ввода ссылок на картинки (или импорт через `public`). |
| **Поиск не реагировал на клик по подсказке** | Замена `onClick` на `onMouseDown` + `stopPropagation` из-за конфликта с `handleClickOutside`. |
| **Переполнение `localStorage` при хранении аватаров** | Сжатие изображений через Canvas (максимальный размер 200x200, качество 0.7). |

## 🚀 Что можно улучшить / добавить

- 🧩 **Каталог** — сейчас это только статическая вёрстка с иконками. Можно реализовать фильтрацию по категориям, пагинацию и сортировку.
- 🔐 **Реальный бэкенд** — заменить `json-server` на полноценный сервер (Express + MongoDB или PostgreSQL) с JWT-авторизацией.
- 🖼️ **Загрузка изображений в админке** — подключить облачное хранилище (Cloudinary, ImgBB) с нормальной поддержкой CORS.
- 📦 **История заказов** — страница с оформленными заказами пользователя.
- 📧 **Уведомления** — тосты (успех/ошибка) вместо `alert`.
- 🔄 **Пагинация товаров** — подгрузка новых товаров при скролле (бесконечная лента).
- 🌐 **Переключение языка** — интернационализация (i18n).
- 📱 **Push-уведомления** (для мобильной версии).
- 🧪 **Тесты** — покрытие ключевых компонентов тестами (Jest + React Testing Library).

## 🛠️ Запуск проекта

### 1. Клонирование и установка

```bash
git clone https://github.com/partikond212/ShopMarket.git
cd ShopMarket
npm install
```

### 2. Запуск сервера разработки

```bash
npm run dev
```

### 3. Запуск `json-server` (фейковое API)

```bash
npm run server
```

Сервер будет доступен по адресу `http://localhost:3001`.

### 4. Сборка для продакшена

```bash
npm run build
```

### 5. Деплой на GitHub Pages

```bash
npm run deploy
```

После этого сайт будет доступен по адресу:  
👉 **[https://partikond212.github.io/ShopMarket/](https://partikond212.github.io/ShopMarket/)**
